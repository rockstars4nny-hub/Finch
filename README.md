# Finch — THE MACHINE

**Aetherverse Intelligence Protocol (AIP)**  
Local operator console for authorized cyber intel, person-of-interest mapping, and IoT fabric recon.

> **Source of truth:** private **[PT](https://github.com/rockstars4nny-hub/PT)** repository (`finch/` + `glass/`).  
> This public repo is the product landing page. Full code ships in PT.

---

## What it is

One engage bar. Auto-routes a **name, address, plate, domain, wallet, or LAN/CIDR** into the right rails:

| You enter | What runs |
|-----------|-----------|
| Name / email / phone / @user | Identity + social map + finance + Footprint |
| **Street address** | Reverse-address → **assessor GIS owners**, deed/PIN/tax card → identity cascade |
| License plate | Plate intel (public listings → VIN) → seller cascade |
| Domain / IP / URL | Cyber intel + bounty recon + fabric enrich |
| `0x` contract | Web3 + **F.O.R.G.E.** (fork-executed proof only) |
| CIDR / private IP | **Glass** fabric: Find IoT, MQTT, BLE/RF, surface ports, SENTINEL export |

**Privacy:** ephemeral by default. Nothing on disk unless you Persist. Opt-in vault is AES-256-GCM.
